# Empire Builder — Side Hustle Grind 🚀

An idle game where you build your empire through side hustles, equipment upgrades, and prestige mechanics.

## How to Play

1. **Click the register** to earn cash
2. **Buy equipment** (laptops, CRM software) to boost click power
3. **Buy businesses** (freelance gigs → digital agencies) for passive income
4. **Prestige** at $500k+ to unlock permanent 50% bonuses

## Themes

Toggle between 5 color palettes:
- 🌇 Sunset — Energetic orange gradient  
- 🌊 Ocean — Calming blue tones

## Local Development

```bash
# Serve with http-server (requires Node.js)
npx http-server entrepreneur-idle -p 8080

# Or just open index.html in your browser
open entrepreneur-idle/index.html
```

## Tech Stack

- Pure HTML/CSS/JS — no frameworks
- LocalStorage for auto-save
- SVG icons, CSS gradients/glassmorphism
- Responsive layout (mobile-friendly)

## Features

- 🔄 **6 Upgrade Tiers** — Freelance → AI Co-Founder  
- 💼 **Equipment Upgrades** — 6 click power boosters  
- ⭐ **Prestige System** — Max level 5, +50% bonus per level  
- 🎨 **Theme Switcher** — Instant color palette changes  
- 📊 **Activity Log** — Track your empire growth
